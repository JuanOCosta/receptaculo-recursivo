# Receptáculo Recursivo

Sitio estático de Juan O. Costa, preparado para GitHub Pages.

## Estructura
- index.html — portada
- relatos.html — relatos
- bitacora.html — bitácora
- archivo.html — archivo
- autor.html — autor
- tienda.html — tienda
- style.css — diseño
- assets/receptaculo.png — identidad gráfica

## Publicación
1. Crear un repositorio público en GitHub.
2. Subir todos estos archivos respetando las carpetas.
3. En Settings → Pages, elegir "Deploy from a branch", rama `main`, carpeta `/ (root)`.
4. GitHub generará la dirección pública del sitio.

Los enlaces de redes sociales están deliberadamente como marcadores (#) hasta que se proporcionen las URLs definitivas.
